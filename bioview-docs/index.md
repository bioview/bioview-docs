BioView is a cross-platform data acquisition application for biomedical and human–computer interface instrumentation. It is designed to be hardware-agnostic, with the capability to drive instruments from National Instruments, BIOPAC Inc, and more to come. BioView is designed to be extensible and configurable via text-based descriptions, making it much more flexible than visual programming alternatives.

If you are looking to install BioView, head over to our instructions on [getting started](setup/downloads.md). Once installed, follow the [quick start](usage/quickstart.md) guide on setting up your projects.
